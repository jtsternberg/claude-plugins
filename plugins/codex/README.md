# codex

Codex-native model stances and delegation discipline for comparing frontier-model behavior.

## Skills

### `sol-delegate`

Use with Sol as the main agent. Keep planning, architecture, judgment, review, and user communication in Sol; route execution to Terra, GPT-5.5, GPT-5.4, or other available models. Luna is a future target when direct model selection supports it; today, reach Luna only through an explicit Hotline/cmux path when that is actually available.

### `fable-mode`

The Fable A/B condition. Use on Terra or another Codex model to adopt the standard associated with Anthropic's most capable model and test whether that competitive frame improves judgment and follow-through.

### `sol-mode`

The Sol A/B condition. Use on Terra or another Codex model to adopt a Sol-level operating standard without delegating. Compare it against `fable-mode` on equivalent tasks.
